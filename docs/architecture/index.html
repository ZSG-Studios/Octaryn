Architecture

Four owners keep presentation, authority, public contracts and game content separate.

Owner Responsibility
Client Window/input, Slang/RHI graphics, RmlUi and presentation.
Server Jolt movement, simulation, edits, world items and persistence.
Shared IDs, commands, manifests and approved module contracts.
Basegame Bundled game rules, terrain/material definitions and assets.

Execution

C17/C++23 systems and C#/.NET 10 modules both participate in the current application. Native scheduling and explicit host bridges keep module access bounded. Generated terrain remains transient; authoritative changes and metadata persist. Client/server file exchange supports the local session, not internet multiplayer.

Graphics

Standalone Slang RHI submits every first-party pass, using Slang SPIR-V, DXIL or Metal source. SDL3 is for platform services. Rendering keeps exact voxel surfaces without LOD. Ray tracing and HDR display output are unfinished.
