Validation

Separate static checks, CPU logic, actual GPU execution and extracted-package verification.

Target Scope
octaryn_validate_static Source/contracts/policy checks
octaryn_validate_cpu Native logic and owner module/server behavior
octaryn_validate_gpu Actual Slang RHI and packaged UI/FSR execution
octaryn_validate_all Explicit aggregate of the three groups

GPU checks require an available backend and driver. A skipped platform is not a passing runtime check. Inspect images as well as logs. Ordinary startup opens the game; use explicit diagnostic/benchmark modes for focused qualification.

Release evidence must identify the archive/checksum, build, tested API, world/settings isolation and actual outcomes. Historical development measurements do not qualify a new package.

Current qualification

Fresh Windows x64 checks passed 600 frames with Native AA on DX12 and Vulkan at radius 4; DX12 also passed radius 32 with 4,225 columns. All three runs reported no warnings/errors and their captures were inspected. These are rendering/UI checks, not FPS benchmarks or sustained-travel guarantees. The native Linux bundle builds on Fedora 44 under WSL2 and its fluid checks pass. A relocated Linux run passed 600 Native AA frames on software llvmpipe; hardware Vulkan remains unqualified. The experimental Fedora 44 binary requires glibc 2.43+ and GLIBCXX_3.4.35. Windows and Linux static and CPU validation aggregates both pass.
