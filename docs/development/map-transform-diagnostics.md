# Runtime scene transform diagnostics

Set `OCTARYN_CLIENT_TRANSFORM_DIAGNOSTICS=1` before startup to enable bounded runtime checks. Optional `OCTARYN_CLIENT_TRANSFORM_FILTER` is a case-sensitive substring of the retained node or mesh name. Names are bounded to 1024 bytes; node, mesh and primitive indices remain available. Diagnostics are disabled by default.

At geometry initialization and every 120 rendered frames, the selected map emits at most 64 `map_transform_source` JSON records and a `map_transform_sources` summary. The record contains the evaluated column-major source node matrix, raw object bounds, cached row-major shader world/normal matrices, determinant/orientation, and expected and submitted world bounds. The source transform is baked into flattened geometry; its shader matrix must be identity. Instanced geometry must use its evaluated source matrix. The inverse-transpose invariant and bounds enclosure are checked independently. Invalid finite values, orientation, normals, source bounds or cached transforms reject load or draw when diagnostics are enabled. Coherent instance pose changes remain valid.

`map_transform_frame` records describe the current camera, primary raster route, frustum toggle, instance revision and available selection feedback. These records use the same cached transforms subsequently passed to primary shader bindings. They do not qualify actual GPU vertex readback, individual GPU cluster visibility, or the original game's source assembly policy. A game-side checker must compare source matrices against its independent placement oracle.

Run `python tools/validation/check_map_transform_trace.py --client-log <log> --out <new-receipt.json>` to validate captured records. Run `python tools/validation/check_map_transform_diagnostics.py --out <new-directory>` for private CPU compilation, adversarial guards and production syntax checks. The latter requires configured native dependency paths and does not build or run the client.
