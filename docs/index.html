Current application

All graphics use Slang shaders through standalone Slang RHI. Windows defaults to DX12; Vulkan is also tested on Windows. The Linux release bundle builds on Fedora 44 under WSL2 and passes a relocated software llvmpipe run; hardware Vulkan and Metal GPU execution remain unqualified. SDL3 handles window/input and RmlUi supplies the pixel-art menus.

The world uses exact voxel geometry without LOD, a creative inventory, server-owned item tosses/pickups, persistent edits, and FSR 2.2.1 reconstruction. Local process communication is integrated; internet/LAN multiplayer is unfinished.

Current qualification

Fresh Windows x64 checks passed 600 frames with Native AA on DX12 and Vulkan at radius 4; DX12 also passed radius 32 with 4,225 columns. All three runs reported no warnings/errors and their captures were inspected. These are rendering/UI checks, not FPS benchmarks or sustained-travel guarantees. The native Linux bundle builds on Fedora 44 under WSL2 and its fluid checks pass. A relocated Linux run passed 600 Native AA frames on software llvmpipe; hardware Vulkan remains unqualified. The experimental Fedora 44 binary requires glibc 2.43+ and GLIBCXX_3.4.35. Windows and Linux static and CPU validation aggregates both pass.
